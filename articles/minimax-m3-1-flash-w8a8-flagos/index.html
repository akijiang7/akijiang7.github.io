MiniMax-M3.1-Flash gets W8A8 quantized versions for nine chip platforms, via FlagOS (not the MiniMaxAI org)

Key points

  • The FlagOS team's FlagRelease account published W8A8 quantized versions of MiniMax-M3.1-Flash on Hugging Face on Oct 19, 2026 (UTC+8). MiniMax's official Hugging Face repository now points to them in a document, FlagOS Multi-Chip Support and Downloads. It says the FlagOS community provides W8A8 quantized versions of the model for nine chip vendors: T-Head (Zhenwu), NVIDIA, MetaX, Hygon, Huawei Ascend, Moore Threads, Iluvatar, Kunlunxin and Tsingmicro. Oct 30, 2026 is the last-modified date of MiniMax's official repository, which contains this pointer document. It is not the release date of the quantized versions.
  • The quantized repositories are published by FlagRelease on Hugging Face and ModelScope, not by the MiniMaxAI organization. The MiniMaxAI HF org has no separate quantized M3.1-Flash repository. Its only M3.1 entry is MiniMaxAI/MiniMax-M3.1-Flash.
  • All nine FlagRelease Hugging Face repositories exist. They were created on Oct 19, 2026 at 09:45 and 18:28–18:29 (UTC+8).
  • According to the document, FlagOS converts and requantizes the model's original QAT NVFP4 weights into W8A8. The official model card says M3.1-Flash itself uses quantization-aware training.

What happened

MiniMax-M3.1-Flash was published on Hugging Face on Oct 17, 2026. The model card describes sparse attention throughout, quantization-aware training of the routed MoE experts and attention paths, and DSpark speculative decoding. The added FlagOS document lists one W8A8 repository per platform. NVIDIA, Huawei Ascend, Kunlunxin and T-Head use "Express" builds named MiniMax-M3.1-Flash-W8A8-<platform>-FlagOS-Express; the others use MiniMax-M3.1-Flash-W8A8-<platform>-FlagOS. Its example runs the T-Head Express build on vLLM-plugin-FL with tensor_parallel_size=8.

Key details

  • NVIDIA build: FlagRelease/MiniMax-M3.1-Flash-W8A8-nvidia-FlagOS-Express
  • The other eight builds are listed on the FlagRelease Hugging Face page and in MiniMax's document.
  • The official card warns that its benchmark "results are for the official weights; third-party quantizations may differ."
  • MiniMax-M3.1-Flash is released under MiniMax's own license (Hugging Face lists it as "other"), so MoxBench publishes a summary only.

What this means for US developers

For US teams on NVIDIA, the relevant build is the NVIDIA W8A8 Express repository. It is a community quantization that MiniMax links to, not an official MiniMax checkpoint, so validate its quality yourself: MiniMax's own scores apply only to the official weights. The other eight builds target Chinese domestic accelerators, which suggests MiniMax is positioning M3.1-Flash for hardware-diverse deployment in China. Check the license terms of both MiniMax's model and each FlagRelease repository before you put them into production.
