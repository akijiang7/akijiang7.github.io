What is Kimi Code CLI

Kimi Code CLI is an AI coding agent that runs in your terminal. It can help you read and write code, execute shell commands, search files and fetch web pages, and it decides its next action on its own based on feedback. It works out of the box with Moonshot AI's Kimi models and can also point to other compatible providers.

Installation

We recommend the official install script; there is no need to install Node.js beforehand.

  • macOS / Linux:
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
  • Windows (PowerShell):
irm https://code.kimi.com/kimi-code/install.ps1 | iex
Windows users also need to install Git for Windows before first launch; Kimi Code CLI uses its Git Bash as the shell environment. If Git Bash is installed in a non-standard path, set KIMI_SHELL_PATH to the absolute path of bash.exe.

Then run in a new terminal session:

kimi --version

For npm installation, upgrade and uninstall, see Getting Started.

Quick start

Enter your project directory and start the interactive interface:

cd your-project
kimi

On first launch, type /login in Kimi Code CLI and choose Kimi Code OAuth or a Moonshot AI Open Platform API key to log in. Once logged in, you can start by having it get familiar with the project:

Core features

  • Binary distribution, zero environment dependencies. Install with one command; no need to pre-install Node.js, no fiddling with PATH, and no conflicts with global modules.
  • Lightning-fast startup. The TUI is ready in milliseconds, so opening a new session carries no mental overhead.
  • Polished TUI experience. An end-to-end refined interface, optimized for long, focused agent sessions.
  • Video as input. Drag screen recordings or demo videos into the conversation and let the agent see things that are hard to describe in words: turn a reference clip into a LUT, cut a long video into a short one, turn a screen recording into code, and more.
  • AI-native MCP configuration. Add, edit and authenticate MCP servers conversationally through /mcp-config, with no hand-written JSON.
  • Rich plugin ecosystem. Install skills, MCP servers and data sources from the plugin marketplace or any GitHub repository; every install shows the trust level of its source.
  • Subagents for focused parallel work. Built-in coder, explore and plan subagents handle subtasks in isolated contexts, keeping the main conversation clean.
  • Lifecycle hooks. Run local commands at key points: intercept high-risk tool calls, audit decisions, send desktop notifications, or connect your own automation scripts.
  • Editor / IDE integration (ACP). Use kimi acp to let Zed, JetBrains or any Agent Client Protocol client drive sessions directly.

Using it in your editor (ACP)

Kimi Code CLI supports the Agent Client Protocol, so ACP-compatible editors / IDEs (Zed, JetBrains…) can drive sessions directly over stdio. Log in once, then point your editor at the kimi acp subcommand; no repeated login is needed.

Taking Zed as an example, add the following to ~/.config/zed/settings.json:

{
  "agent_servers": {
    "Kimi Code CLI": {
      "type": "custom",
      "command": "kimi",
      "args": ["acp"],
      "env": {}
    }
  }
}

Then start a new conversation in Zed's Agent panel. For JetBrains configuration and troubleshooting, see Using in IDEs; for the full capability matrix, see the kimi acp reference.

Local development

Requirements: Node.js ≥ 24.15.0, pnpm 10.33.0.

git clone https://github.com/MoonshotAI/kimi-code.git
cd kimi-code
pnpm install
pnpm dev:cli    # run the CLI in development mode
pnpm test       # run tests
pnpm typecheck  # TypeScript checks
pnpm lint       # run oxlint
pnpm build      # build all packages

For the full contribution process, see CONTRIBUTING.md.

What this means for US developers

The Chinese README matches the English one almost line for line, which suggests Moonshot is aiming at both markets equally. For US teams, the key points are the MIT license, a single-binary install that avoids Node.js dependency problems, and ACP support that plugs into Zed and JetBrains. Lifecycle hooks let you block risky tool calls, a practical guardrail for company rollouts. By default the agent talks to Moonshot's hosted Kimi models. If your code can't leave your network, set it up for another compatible provider and check what data the CLI sends before rolling it out.
