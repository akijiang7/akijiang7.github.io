DeepSeek this week: Nov 3 web/API outage and Harness v0.2.2-alpha.3

Key points

  • Outage: DeepSeek's status page recorded "DeepSeek 网页/API 部分中断（DeepSeek Web/API Partially Unavailable）" on Nov 3, 2026, from 08:58 to 10:48 UTC (16:58 to 18:48 UTC+8), 1 hour 49 minutes. Affected: DeepSeek V4 Pro API Service, DeepSeek V4.1 Flash API Service, and Chat Service. Resolved; no root cause given.
  • Harness release: @deepseek-ai/dsh 0.2.2-alpha.3 was published to npm on Nov 3, 2026 at 07:48 UTC (15:48 UTC+8) under the alpha dist-tag.

Outage details

Full write-up: DeepSeek web and API partially unavailable for 1h49m on Nov 3.

  • 08:58 Investigating: "The issue is being investigated to identify the cause."
  • 09:06 Monitoring: "A fix has been implemented and the results are being monitored." (repeated through 10:41)
  • 10:48 Resolved: "The incident has been resolved and service has been restored."

DeepSeek Harness v0.2.2-alpha.3

Quoted from the official release notes:

  • Code review and worktrees: "Unify code review and worktree access in the experimental change-request and worktree feature. Browse local and PR diffs through a searchable file tree and per-file navigation, quote selected code and comments to the Agent, and track checks and reviews."
  • Scheduled tasks: "Unify scheduled-task management across the Host with manual creation, direct editing, and prefilled prompts for creation in a Session. Retain drafts, support conflict review, and run tasks in reusable or new Sessions."
  • Multi-file edits: "Add apply_patch, disabled by default, to create, edit, delete, and move multiple files in one call, with changes available in Review."

Migration note from the same release: "Users who enabled the standalone plugin must manually remove @deepseek-ai/dsh-experimental-tool-worktree from dsh.profile.bundles in their profile." The release also turns off read-before-write and external-change checks by default. Sandbox limits and Review stay in place.

This is an alpha build. As of Nov 5 the npm latest tag still points to 0.2.1-rc.5, and next points to 0.2.2-rc.1.

What this means for US developers

The outage ran from about 3:58 to 5:48 AM US Eastern (EST). Keep retry or fallback logic in place for V4 Pro and V4.1 Flash. If you try the Harness alpha, apply_patch is off unless you enable it. If you used the standalone worktree plugin, update your profile.
