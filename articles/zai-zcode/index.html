Z.ai's ZCode: Zhipu's open coding workbench ships desktop, web and terminal agents from one repo

Z.ai, the company behind the GLM models (formerly Zhipu AI), has updated ZCode, its open-source AI coding workbench, to version 3.17.1. The repository includes a desktop app, a browser interface, a terminal agent, a backend service and the agent CLI and runtime source, all in one place.

What happened

The ZCode README (in Chinese, translated here) describes the project as an "AI programming workbench." It has shipped frequent releases: v3.14.3 in late September, then v3.15.1, v3.15.4, v3.16.1 and v3.16.2 in October, and v3.17.1 on October 30. The repository contains the clients, backend, shared UI and the agent CLI source under apps/zcode-cli/, which is a normal directory rather than a git submodule.

Key details

  • Three ways to use it: an Electron desktop app (pnpm dev:desktop), a web interface with a local backend (pnpm dev:web, with the web UI on port 5173 and the backend on 3030), and a command-line release started with zcode.
  • Command-line release: zcode alone opens the terminal UI. zcode --web starts the web interface (options include --workspace, --port and --no-open). Any other arguments go to the agent CLI. Both modes run locally without Electron.
  • Security defaults: web mode listens on 127.0.0.1 with no access token by default. If you bind to a non-local address, such as --host 0.0.0.0 for LAN access, an access token is generated by default. API and WebSocket auth can be set with ZCODE_SERVER_AUTH_TOKEN.
  • Remote work: SSH and WSL remote projects are supported. Runtime assets are uploaded over SFTP.
  • Build requirements: Git, Node.js 24.14.0 and pnpm 10.33.2. Run pnpm bootstrap to set up.
  • CLI docs: model configuration, non-interactive calls, tools and extensions, batch evaluation and trajectory recording are covered in the CLI usage guide.
  • License: listed as Apache 2.0 in the repository metadata. The README points to NOTICE.md for licensing, third-party copyright and data-risk notes.

What this means for US developers

ZCode joins Qwen Code and Kimi Code CLI in a clear trend: every major Chinese model lab now ships its own open-source coding agent. ZCode stands out for bundling desktop, web and terminal front ends around one agent runtime. Its built-in batch evaluation and trajectory recording should interest teams benchmarking agents. The main documentation is in Chinese and the build is a large pnpm monorepo, so expect more setup work than a one-line install. Read NOTICE.md for data-handling details before connecting it to proprietary code.
