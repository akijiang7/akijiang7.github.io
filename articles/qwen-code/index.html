Qwen Code: Alibaba's open-source coding agent expands beyond the terminal

Qwen Code, the Qwen team's open-source AI coding agent has about 28,900 GitHub stars (as of Nov 2, 2026). It now runs in the terminal, in editors, as a desktop app, in the browser and in chat apps, and it works with OpenAI, Anthropic, Gemini and Qwen APIs as well as local models.

What happened

The current README describes Qwen Code as "the open-source AI coding agent for your terminal, editor, desktop, browser, and chat." Built-in agent features include Auto-Memory, Auto-Skills, SubAgents, Agent Teams and MCP support. The team says the project is "actively iterating on itself": it uses its own agent and models to file issues, open pull requests, review code and run tests.

Key details

  • Interfaces: terminal (qwen), a desktop app for macOS, Windows and Linux, an experimental web UI (qwen serve --open), and plugins for VS Code, Zed and JetBrains. It also connects to Telegram, DingTalk, WeChat and Feishu.
  • Automation: headless mode (qwen -p "...") for scripts and CI/CD, SDKs for TypeScript, Python and Java, and an experimental daemon that serves clients over HTTP + SSE (ACP). Computer-use tools are available as native MCP tools.
  • Model providers: OpenAI, Anthropic, Gemini and Qwen APIs, any third-party provider, or local models via Ollama or vLLM. You can switch providers at runtime.
  • Install: a standalone script for Linux/macOS and Windows, npm install -g @qwen-code/qwen-code@latest (Node.js 22+), or brew install qwen-code. Run /auth inside a session to set a provider and API key.
  • License: Apache 2.0 (per the repository's license metadata).

What this means for US developers

Qwen Code is a credible open-source alternative to proprietary terminal agents, and it is not tied to Qwen models. You can point it at Claude, GPT, Gemini or a local vLLM server. Headless mode and the SDKs make it practical to embed in CI or internal tools without per-seat licensing. One detail to note: the default install script downloads from an Alibaba Cloud bucket in Hangzhou. Teams with supply-chain policies may prefer the npm or Homebrew route, or building from source.
