Baidu's Unlimited-OCR 2 parses documents of any length with a fixed attention budget

Baidu has released Unlimited-OCR 2, an MIT-licensed vision-language model for document parsing. It is built to handle very long documents, including ones with hundreds of pages, without memory and latency growing as the document gets longer.

What happened

The first Unlimited-OCR appeared in June 2026, presented as an attempt to push DeepSeek-OCR "one step further." Version 2 adds Sparse Reference Sliding Window Attention (SR-SWA). Baidu says it compresses the text-visual attention across a very long sequence into a fixed-size set of working references, 512 tokens for example. That keeps per-step decoding latency and memory nearly constant however long the document is, which Baidu calls "unlimited-horizon parsing" within a finite context window. Alongside the model, Baidu released MarathonDocBench, a benchmark for ultra-long document parsing, and published a paper on arXiv on November 2.

Key details

  • Task: image-text-to-text OCR and document parsing, multilingual.
  • License: MIT.
  • Parameter count: not stated on the model card.
  • Claimed results: Baidu reports state-of-the-art results on both dozens-of-pages benchmarks (such as MPDocBench) and hundred-page benchmarks (MarathonDocBench). The model card gives no single headline number.
  • How to run: with Transformers (tested on Python 3.10, torch 2.13.0, transformers 4.52.1, on an A800-80GB) using trust_remote_code=True. infer_multi parses all pages of a document in one request so the model can use context across pages. infer handles single pages with dynamic tiling. For serving, Baidu recommends a customized SGLang build, and the model card documents memory-tuning flags for it.
  • Other access: ModelScope (PaddlePaddle/Unlimited-OCR-2), Baidu Cloud, and a Hugging Face Space demo. Training is supported through ms-swift.

What this means for US developers

If you are building RAG or document-ingestion pipelines over long contracts, filings or manuals, the main pitch is parsing a whole document in one pass with cross-page context, without splitting it into chunks. The MIT license makes commercial use simple. Expect some setup effort. The model needs trust_remote_code, pinned library versions and a custom SGLang wheel for production serving. Test it on your own document types against your current OCR stack before switching.
