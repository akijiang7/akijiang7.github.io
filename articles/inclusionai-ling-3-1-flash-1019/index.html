inclusionAI's Ling-3.1-flash-1019: a 560B MIT-licensed MoE with 25B active and a 1M-token context

Read the full text ↓

Key points

  • inclusionAI released Ling-3.1-flash-1019, an upgraded version of Ling-3.1-flash with 560B total parameters, 25B active per token, and a 1M-token context window.
  • The license is MIT (confirmed via the Hugging Face API).
  • The architecture is a hybrid-linear MoE: 63 KDA layers plus 9 Gated MLA layers in a 7:1 ratio, 512 routed experts, 8 active.
  • inclusionAI reports gains over the previous version: Artificial Analysis Intelligence Index v4.3.2 of 44 (up from 41), AA-Briefcase from about 1400 to 1524 Elo, and AutomationBench-AA from 62% to 68%.
  • It runs on SGLang (a day-0 Docker image) and vLLM. The reference server setup is 8 × H200, or 4 × GB300.

What happened

inclusionAI posted Ling-3.1-flash-1019 on Hugging Face on October 27, 2026. The model card says further post-training brought "significant improvements in reasoning and real-world agentic capabilities". It also reports gains on scientific benchmarks: CritPt went from 18% to 26% and SciCode from 54% to 57%. Alongside the model, inclusionAI points to a public training-content summary (PDF) in its AI-Transparency repository.

Key details

  • Size: 560B total, 25B active. There are 4 dense layers, 512 routed experts plus 1 shared expert, and 8 activated experts.
  • Layers: 63 KDA and 9 Gated MLA (7:1). There are 64 attention heads, a hidden size of 4096 and a vocabulary of 157,184.
  • Context: 1M tokens.
  • How to run: with SGLang, pull lmsysorg/sglang:dev-ling-3.1-flash, then launch with --tp 8 --ep 8 --speculative-algorithm NEXTN on 8 × H200, or --tp 4 --ep 4 on 4 × GB300. With vLLM, use the vllm branch with --tool-call-parser ling3 --reasoning-parser ling3 and MTP speculative decoding. The SGLang cookbook covers H200, GB300, H800, H100 and B200.
  • Recommended sampling: temperature=1.0, top_p=0.95, top_k=20, with enable_thinking: true.
  • Benchmarks: all of the figures above are as reported on the model card.
  • License: MIT.

Introduction

We introduce Ling-3.1-flash-1019, an upgraded version of Ling-3.1-flash, with 560B total parameters, 25B active parameters per token, and a 1M-token context window. With further post-training optimizations, Ling-3.1-flash-1019 demonstrates significant improvements in reasoning and real-world agentic capabilities. Its AA-Briefcase score rises from approximately 1400 to 1524 Elo, while performance on AutomationBench-AA increases from 62% to 68%. The model also makes gains on scientific benchmarks, including CritPt (18% → 26%) and SciCode (54% → 57%). Overall, it scores 44 on the Artificial Analysis Intelligence Index v4.3.2, up from 41 for its predecessor. These gains highlight the model's improved capabilities in complex reasoning, multi-step task execution, and agentic workflows across diverse real-world scenarios.

Quickstart

SGLang (Recommended)

The day-0 SGLang image includes Ling-3.1-flash support, MTP (NEXTN) speculative decoding, and Hopper decode optimizations:

docker pull lmsysorg/sglang:dev-ling-3.1-flash
Run Inference

Server (8 × H200, TP8 + EP8):

docker run --gpus all --network host --ipc=host --rm \
  lmsysorg/sglang:dev-ling-3.1-flash \
  python3 -m sglang.launch_server \
    --model-path inclusionAI/Ling-3.1-flash \
    --tp 8 --ep 8 \
    --speculative-algorithm NEXTN \
    --host 0.0.0.0 --port 30000

On 4 × GB300, use --tp 4 --ep 4 instead. Hopper decode optimizations (optional, ~10% faster batch-1 decode) can be enabled with SGLANG_ENABLE_FP8_BLOCK_GEMV=1 and SGLANG_ENABLE_FUSED_KDA_OUTPUT_QUANT=1.

Client

curl -s http://localhost:30000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "Ling-3.1-flash",
       "messages": [{"role": "user", "content": "What is the capital of France?"}],
       "chat_template_kwargs": {"enable_thinking": true},
       "stream": true,
       "temperature": 1.0,
       "top_k": 20,
       "top_p": 0.95}'

Verified recipes for H200, GB300, H800, H100, and B200, plus HiCache (Mooncake L3), reasoning on/off, tool calling, and measured accuracy/speed numbers, are in the SGLang Ling-3.1-flash cookbook.

vLLM

Environment Preparation
pip install uv

uv venv ~/my_ling_env

source ~/my_ling_env/bin/activate

git clone -b vllm https://github.com/vllm-project/vllm.git

cd vllm

VLLM_USE_PRECOMPILED=1 uv pip install --editable . --torch-backend=auto
Run Inference

Server

vllm serve "$MODEL_PATH" \
    --port "$PORT" \
    --trust-remote-code \
    --served-model-name auto \
    --tensor-parallel-size 8 \
    --gpu-memory-utilization 0.85 \
    --enable-prefix-caching \
    --enable-expert-parallel \
    --mamba-cache-mode align \
    --enable-auto-tool-choice \
    --tool-call-parser ling3 \
    --reasoning-parser ling3 \
    --speculative-config '{"method":"mtp","num_speculative_tokens":3}'

Client It is recommended to use the sampling parameters (temperature=1.0, top_p=0.95, top_k=20) and set enable_thinking to true for better performance.

What this means for US developers

Ling-3.1-flash-1019 is a large agent-oriented model under a plain MIT license: no usage caps, no custom terms. That makes it one of the simplest frontier-scale open weights to clear with legal. With 25B active parameters it is cheaper to serve than its size suggests, but you still need a multi-GPU node (8 × H200 or 4 × GB300 in the reference setup). The model card links an OpenRouter listing, so you can try it before you self-host. The benchmark gains are inclusionAI's own and mostly use Artificial Analysis metrics, so test it on your own agent tasks. The published training-content summary helps if your compliance team asks where the training data came from.
