Tencent Hy-Nomas: an Apache-licensed interactive world model you can steer with text and camera paths

Tencent Hunyuan has open-sourced Hy-Nomas, a video "world generation" model. It builds a scene one video segment at a time and lets you redirect it between segments with text instructions and camera trajectories. It outputs 720×1280 video at 24 FPS, and Tencent provides a configuration that runs on a single RTX 4090.

What happened

According to the model card, Hy-Nomas combines a segment-wise autoregressive diffusion transformer with a Qwen text encoder, camera-conditioning modules and a PixelUMM video decoder. A persistent KV cache carries context from one segment to the next, so a world stays consistent as you extend it. Between segments, users can add objects, change the style or scene, describe actions or move the camera. Tencent also released Hy-Nomas-Bench, which has 280 test cases across four benchmarks: multi-turn text interaction, camera navigation, interleaved text and camera control, and spatial memory.

Key details

  • Architecture: a dense dual-stream MMDiT with 54 blocks. The text encoder is the language component of Qwen2.5-VL-7B-Instruct. The decoder is a fine-tuned PixelUMM transformer with 36 layers.
  • Output: 720×1280 at 24 FPS. The distilled configuration uses 8 denoising steps per segment.
  • Hardware: the standard configuration uses 8-way sequence parallelism and needs eight GPUs. A low-memory configuration with an INT8 DiT and FP8 decoder targets a single NVIDIA GeForce RTX 4090.
  • Extras: an optional Cinematic LoRA, and a Robotics LoRA trained on a real-world robotic-arm dataset. A separate prompt-enhancement service, Nomas-PE, is required by the web demo.
  • License: Apache 2.0.
  • How to run: clone Tencent-Hunyuan/Hy-Nomas and use the pre-packaged Docker image, which Tencent strongly recommends. Download the model assets and keep the DiT/, VAE/ and PE/ layout. A Diffusers version (tencent/Hy-Nomas-Diffusers) is also available.

What this means for US developers

Interactive world models are an active area for game prototyping, simulation and robotics data. Hy-Nomas is a permissively licensed option you can run on a consumer GPU, and that combination is still uncommon. The camera-trajectory control and the robotics LoRA make it worth a look for teams generating synthetic training video. Expect a heavy setup: several checkpoints, a separate prompt service for the demo, and a Docker-first workflow. Treat the single-4090 path as the place to start evaluating.
