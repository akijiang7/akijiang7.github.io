DeepSeek open-sources DeepInfer, the inference engine behind its production service

Read the full text ↓

Summary

DeepSeek has released DeepInfer, the high-performance inference framework it describes as powering its own large-scale production services. The open-source version handles offline inference and currently supports one model, DeepSeek-V4.1-Flash. It runs on NVIDIA SM100 GPUs and Huawei Ascend 950 NPUs.

What happened

According to the README, DeepInfer packages the kernels, model runtime and sampler that DeepSeek uses in production. It is built on DeepSeek's earlier open kernel libraries: FlashMLA, DeepGEMM, DeepEP, TileKernels and DeepSelect. DeepSeek is clear that this is not a complete serving stack. Three pieces are left out: a KV cache system, VE/prefill/decode disaggregation (though most of the engine functionality for it is already implemented), and load balancing across data-parallel replicas.

Key details

  • Supported model: DeepSeek-V4.1-Flash. The default checkpoint is deepseek-ai/DeepSeek-V4.1-Flash-1017, which downloads from Hugging Face on first run.
  • Parallelism: attention data parallel / balanced context parallel, and MoE expert parallelism with EPLB.
  • Decoding speedups: DSpark draft tokens with confidence-scheduled verification (DEEPINFER_ENABLE_MTP_VARLEN=1; the default maximum draft length is 5), plus "SWA bounded replay", which cuts prefill work by replaying only a bounded suffix.
  • Reproducibility: a batch-invariant mode keeps results identical whatever the batch composition, and a deterministic sampling mode gives identical outputs for identical inputs and seeds. Both are NVIDIA-only.
  • Structured outputs: constrain generation to a regex, JSON schema or EBNF grammar.
  • Requirements: Linux, GCC 13 or newer, Python 3.12, and CUDA 13 (NVIDIA) or CANN 9.2 (Ascend). Build with ./build.sh, then run python examples/offline_inference.py.
  • Performance: DeepSeek publishes prefill and decode Pareto charts measured on 4 SM100 GPUs (prefill) and 64 (decode).
  • License: Apache 2.0.

What this means for US developers

Most teams will keep using vLLM or SGLang, but DeepInfer gives a direct look at how DeepSeek serves its own models. Batch-invariant inference and deterministic sampling stand out: they matter for evals, regression tests and anyone who needs reproducible outputs. Practical reach is narrow for now. It supports one model, needs SM100-class (Blackwell) NVIDIA hardware or Huawei Ascend, and lacks the KV cache and disaggregation layers a real service needs. The Apache 2.0 license allows commercial reuse, so expect ideas and kernels from it to show up in the mainstream open-source engines.

DeepInfer

DeepInfer is the high-performance inference framework that powers DeepSeek's large-scale production services. This open-source release provides offline inference with the core features needed for serving at scale.

Supported models:

  • DeepSeek-V4.1-Flash

Supported features:

  • Optimized kernels, model and sampler runtime
  • Parallelism: Attention DP / balanced CP, MoE EP + EPLB
  • DSpark and confidence-scheduled verification
  • SWA bounded replay
  • Asynchronous scheduling (zero-overhead batch scheduler)
  • Batch-invariant inference
  • Deterministic sampling
  • Structured outputs

Feature details and configuration

  • Optimized kernels: FlashMLA, DeepGEMM, DeepEP, TileKernels, DeepSelect, and custom TileLang kernels.
  • DSpark and confidence-scheduled verification: accelerate decoding with draft tokens and use confidence estimates to schedule verification. Set DEEPINFER_ENABLE_MTP_VARLEN=1; DEEPINFER_USE_NEXTN_DECODE controls the maximum draft length (default: 5).
  • Decoder SWA bounded replay: reduce decoder prefill work by replaying only a bounded suffix. Set DEEPINFER_YOCO_PREFILL_TRUNCATION_MODE=compact and DEEPINFER_YOCO_PREFILL_KEEP_TOKENS=140 for the default V4.1 settings; the retained suffix must cover the SWA window plus the maximum backtracking length.
  • Asynchronous scheduling: overlap CPU batch scheduling with device execution. Enabled by default.
  • Batch-invariant inference: keep model results identical across different batch compositions. Enable with DEEPINFER_BATCH_INVARIANT=1 (NVIDIA only).
  • Deterministic sampling: produce identical outputs for identical input tokens and sampling parameters. Set DEEPINFER_BATCH_INVARIANT=1 DEEPINFER_ENABLE_MTP_VARLEN=0 and pass a fixed seq_seed to SamplingParams (NVIDIA only).
  • Structured outputs: constrain generation to a regex, JSON schema, or EBNF grammar. Pass so_args={"schema_type": ..., "schema": ...} to SamplingParams; see examples.

Supported hardware:

  • NVIDIA SM100 GPUs
  • Huawei Ascend 950 NPUs

Required for a complete inference service (not included in this release):

  • A KV cache system
  • VE/Prefill/Decode disaggregation (most required engine functionality is already implemented)
  • Load balancing across data-parallel replicas for both prefill and decode

Getting started

Prerequisites

  • Linux
  • GCC >= 13.0
  • Python 3.12
  • CUDA 13 (NVIDIA only)
  • CANN 9.2 (Ascend only)

Build from source

Before building DeepInfer, please create and activate an empty Python 3.12 environment.

# Use `ascend` instead for the Ascend platform
# Keep it exported in the environment where you run DeepInfer
export DEEPINFER_ACCELERATOR=nvidia
./build.sh

Offline inference

The default checkpoint, deepseek-ai/DeepSeek-V4.1-Flash-1017, is downloaded into the Hugging Face cache on the first run; set DEEPINFER_HF_MODEL_DIR=/path/to/DeepSeek-V4.1-Flash-1017 to run from a local copy instead.

python examples/offline_inference.py

See examples for details.
