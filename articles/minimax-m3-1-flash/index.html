MiniMax-M3.1-Flash: a 428B-parameter multimodal MoE with a 1M-token context, built for agents and coding

Summary

MiniMax has published open weights for MiniMax-M3.1-Flash, a native multimodal mixture-of-experts (MoE) model aimed at coding, agentic workflows, computer use and cybersecurity. It accepts text, image and video input, and its context window goes up to 1 million tokens.

What happened

The new Flash release builds on MiniMax-M3. According to the model card, it keeps M3's core MoE architecture and makes three changes. First, sparse attention now runs through the whole model: the first three full-attention layers have been replaced with MiniMax Sparse Attention (MSA). Second, the routed experts and attention paths were quantized during training (quantization-aware training) to cut memory use and make serving cheaper. Third, a new speculative decoding method called DSpark replaces the earlier EAGLE-style MTP approach, and the draft head ships with the weights.

Key details

  • Parameters: about 428B total, 23B active per token.
  • Inputs / output: text, image and video in; text out.
  • Context window: up to 1,000,000 tokens. MiniMax notes that how much context you can actually use, and at what throughput, depends on GPU memory and serving setup.
  • License: custom "minimax-community" license (tagged other on Hugging Face). Read the LICENSE file before commercial use.
  • How to run: download with hf download MiniMaxAI/MiniMax-M3.1-Flash, then serve with SGLang, vLLM or TokenSpeed (each has a recipe). Support for Transformers, KTransformers, unsloth and ATOM is listed as in progress. FlagOS covers multi-chip deployment. It is also available through the MiniMax API and MiniMax Code.
  • Recommended settings: temperature=1.0, top_p=0.95. Reasoning effort is set in the chat template: low, medium, high, xhigh or max.
  • Benchmarks (as reported by MiniMax): 76.2 on BankerToolBench, 73.7% on DeepSWE v1.1, 61.7 on OSWorld 2.0, 29.6 on Agents' Last Exam and 82.2 on CyberGym. MiniMax says these results are for the official weights and that third-party quantizations may score differently.

What this means for US developers

M3.1-Flash is one of the larger open-weight agent models available today, and with only 23B parameters active per token it should be cheaper to run than its 428B total suggests. Shipping the speculative-decoding head and support in mainstream servers (vLLM, SGLang) on day one lowers the cost of testing it. Two caveats. A 428B model still needs multi-GPU hardware even with quantization-aware training. And the license is a vendor community license, not Apache or MIT, so legal should review it before you put it in a product. MiniMax's comparison table pits the model against DeepSeek, Kimi, GLM and closed frontier models. Rerun the agent and coding benchmarks on your own tasks before you rely on those numbers.
