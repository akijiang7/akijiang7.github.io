Shanghai AI Lab's Atria Dawn: an MIT-licensed agent model built on 744B GLM-5.2

Shanghai Artificial Intelligence Laboratory has released Atria Dawn, an agentic model built on the 744B-parameter MoE foundation model GLM-5.2. It targets research and engineering work that involves tool use and long multi-step tasks. The weights are released under the MIT license with a 512K-token context window.

What happened

The lab describes Atria Dawn as a model meant to push open-ended problems toward "executable, verifiable, and reproducible" results. In practice that means covering the whole loop: analyzing the problem, designing a solution, calling tools, writing code, running experiments, analyzing results and recovering from failures. The model card names four focus areas. Discovery covers deep research and turning questions into experimental plans. Creation covers software, apps, games, visualizations and ML systems. Delivery covers reports, presentations and other structured documents. Cybersecurity covers analyzing, validating and fixing vulnerabilities in authorized environments.

Key details

  • Base model: GLM-5.2, a 744B-parameter MoE.
  • Variants: Atria Dawn and Atria Dawn FP8 (full release, 512K context), plus Atria Dawn Preview and Preview FP8 (256K context). All are on Hugging Face and ModelScope.
  • Modality: text input only. The hosted endpoint rejects images.
  • License: MIT for both code and weights.
  • How to run locally: SGLang v0.5.13.post1+ or vLLM v0.23.0+, using the existing GLM-5.2 recipes.
  • Hosted access: an international API console, with OpenAI-compatible (https://discovery-api.intern-ai.org.cn/v1) and Anthropic-compatible endpoints. The model card includes configuration snippets for Codex and other agent harnesses. The model name is Atria-Dawn.
  • Benchmarks: the lab publishes a comparison table covering search, coding, tool use, productivity and security tasks, which it says matches its official website. We have not reproduced it here. See the source.

What this means for US developers

Atria Dawn is a large agent-tuned model under a fully permissive license, and that combination is uncommon. MIT on the weights means no user caps or usage clauses to negotiate. Because it inherits GLM-5.2's architecture, existing vLLM and SGLang setups for GLM should work with little change. Self-hosting a 744B MoE is still a multi-node job, even with the FP8 variant. Note too that the hosted API runs on Chinese infrastructure (intern-ai.org.cn), which some US companies will rule out for data-governance reasons. Self-hosting avoids that.
