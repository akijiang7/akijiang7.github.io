WeChat's WeVisOne-VL: one small Qwen3-VL model for detection, counting, OCR, segmentation and matting

Read the full text ↓

Summary

Tencent's WeChat Vision team has released WeVisOne-VL, a family of small vision-language models (2B and 4B parameters) that handle many perception tasks in one model. Tasks run from object detection to pixel-accurate image matting. The models are built on Qwen3-VL and released under Apache 2.0.

What happened

The name stands for "WeChat Vision All-in-One." The model card says it unifies object-level perception (open-vocabulary detection, referring localization, counting, pointing and OCR) with pixel-level perception (referring segmentation and image matting). WeVisOne-VL adds a small mask decoder that turns predicted boxes into full-resolution masks and alpha mattes. A paper is on arXiv (2610.31329), and there is a project page.

Key details

  • Sizes: 2B and 4B, both on Hugging Face.
  • Base: Qwen3-VL.
  • Output format: dedicated coordinate tokens for normalized boxes and points. The model returns None when the queried object is absent.
  • Mask decoder: a required mask_decoder.pt file (about 9.6M parameters) with a visual feature adapter, a box-guided query decoder and a dense prediction head that outputs full-resolution alpha mattes.
  • How to run: install the wevisone_vl package from GitHub, then call WeVisOneVL("tencent/WeVisOne-VL-4B", device="auto", dtype="bfloat16") and model.predict(image, task="matting", query="person").
  • Limitations: single-image, single-turn only; video is rejected by the pixel decoder. There is no chain-of-thought reasoning. Fine matte edges are sensitive to resolution, occlusion, transparency and prompt wording.
  • Intended use: research in grounding, counting, OCR localization, segmentation and matting. The model is not intended for autonomous high-impact decisions or for identifying individuals.
  • License: Apache 2.0 for Tencent-authored code. Third-party components keep their own licenses.

What this means for US developers

In our view, pixel-level output is the differentiator here: many open VLMs we track stop at bounding boxes. If your pipeline chains a detector, an OCR engine and a segmentation model, WeVisOne-VL offers a single small model that takes natural-language queries. At 2B to 4B parameters, it fits on modest GPUs. It looks useful for e-commerce image cleanup, document region extraction and labeling tools. The model card frames the release as research-oriented. The Apache license allows commercial use, but check the third-party component licenses and test the matting quality on your own images before shipping.

WeVisOne-VL: Unified Visual Perception from Objects to Pixels

Paper: WeVisOne-VL: Unified Visual Perception from Objects to Pixels | Project Page: WeVisOne-VL

WeVisOne-VL (WeChat Vision All-in-One) is a unified vision-language model developed by WeChat Vision, Tencent Inc. Built upon Qwen3-VL, it unifies object-level perception (open-vocabulary object detection, referring localization, object counting, object pointing, and OCR) and pixel-level perception (referring segmentation and promptable alpha matting) through structured next-token prediction and a lightweight 9.6M-parameter pixel decoder.

Quick Start

Install the inference package from GitHub, then:

from PIL import Image
from wevisone_vl import WeVisOneVL

model = WeVisOneVL("tencent/WeVisOne-VL-4B", device="auto", dtype="bfloat16")
image = Image.open("example.jpg").convert("RGB")
result = model.predict(image, task="matting", query="person", temperature=0.0)
print(result.response, len(result.masks))

Architecture & Released Revision

The model uses dedicated coordinate tokens (<0> ... <1000>) to represent normalized bounding boxes and points, returns None when a queried target is absent, and emits a special instance token (<OBJ>, token ID 152678) after each predicted box for dense tasks.

The attached mask_decoder.pt (9,609,764 parameters) is a required core component that combines:

  • A Visual Feature Adapter over multi-level Qwen3-VL pre-merging ViT features;
  • A Box-Guided Query Decoder with 6 deformable cross-attention blocks initialized from the <OBJ> hidden state and Fourier-encoded box prior;
  • An Instance-Conditioned Dense Prediction Head with FullCanvasAlphaCascadeHead (refining predictions across S/4, S/2, and S/1 to output full-resolution continuous alpha mattes at stride 1).

Intended Use

The release is intended for research in visual grounding, referring localization, pointing, counting, OCR localization, referring segmentation, and image matting. It is not intended to make autonomous high-impact decisions or to identify individuals.

Limitations

  • Fine alpha boundaries remain sensitive to image resolution, severe occlusion, complex transparency, and prompt phrasing.
  • For inference efficiency, the model directly generates structured outputs without explicit chain-of-thought (CoT) reasoning, and currently targets single-turn image perception (video grids are rejected by the pixel decoder).
