WeChat's WeVisOne-VL: one small Qwen3-VL model for detection, counting, OCR, segmentation and matting

Tencent's WeChat Vision team has released WeVisOne-VL, a family of small vision-language models (2B and 4B parameters) that handle many perception tasks in one model. Tasks run from object detection to pixel-accurate image matting. The models are built on Qwen3-VL and released under Apache 2.0.

What happened

The name stands for "WeChat Vision All-in-One." The model card says it unifies object-level perception (open-vocabulary detection, referring localization, counting, pointing and OCR) with pixel-level perception (referring segmentation and image matting). Most open VLMs stop at bounding boxes. WeVisOne-VL adds a small mask decoder that turns predicted boxes into full-resolution masks and alpha mattes. A paper is on arXiv (2610.31329), and there is a project page.

Key details

  • Sizes: 2B and 4B, both on Hugging Face.
  • Base: Qwen3-VL.
  • Output format: dedicated coordinate tokens for normalized boxes and points. The model returns None when the queried object is absent.
  • Mask decoder: a required mask_decoder.pt file (about 9.6M parameters) with a visual feature adapter, a box-guided query decoder and a dense prediction head that outputs full-resolution alpha mattes.
  • How to run: install the wevisone_vl package from GitHub, then call WeVisOneVL("tencent/WeVisOne-VL-4B", device="auto", dtype="bfloat16") and model.predict(image, task="matting", query="person").
  • Limitations: single-image, single-turn only; video is rejected by the pixel decoder. There is no chain-of-thought reasoning. Fine matte edges are sensitive to resolution, occlusion, transparency and prompt wording.
  • Intended use: research in grounding, counting, OCR localization, segmentation and matting. The model is not intended for autonomous high-impact decisions or for identifying individuals.
  • License: Apache 2.0 for Tencent-authored code. Third-party components keep their own licenses.

What this means for US developers

If your pipeline chains a detector, an OCR engine and a segmentation model, WeVisOne-VL offers a single small model that takes natural-language queries. At 2B to 4B parameters, it fits on modest GPUs. It looks useful for e-commerce image cleanup, document region extraction and labeling tools. The model card frames the release as research-oriented. The Apache license allows commercial use, but check the third-party component licenses and test the matting quality on your own images before shipping.
